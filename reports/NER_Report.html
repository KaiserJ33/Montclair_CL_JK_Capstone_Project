Named entity recognition in usernames

Not all usernames, account links, or source details could be independently verified. NER labels are model predictions, not verified identities or facts about account holders. No completed human-labelled reference set was available to measure recognition accuracy.

What was measured

The saved analysis used spaCy 3.8.14 with the English transformer model en_core_web_trf. It examined 234 distinct Class A strings, 19,957 distinct platform–handle records from Class B, and a sample of 19,957 Class C records. Class C was sampled from 25,865,739 Reddit records using seed 42. The saved description specifies random-priority sampling. The exact sample and original model-running script were not available in the recovered files.

Each username was analysed as supplied and after light normalization. The saved settings describe removal of a leading @, splitting of CamelCase, delimiters, and letter–digit boundaries, and punctuation cleanup. No title-casing was added. The configured analytic labels are listed in ner_configuration.json. Detection rates count usernames with at least one of those labels.

Main results

After normalization, detection rates were about 54.70% for Class A, 74.65% for Class B, and 54.16% for Class C. Class B had more detections than A or C. The A–C difference was small and was not statistically significant after correction. Detection is not the same as correct recognition.

Raw versus normalized input

The paired McNemar test checks whether normalization changes detection within the same usernames. The two disagreement columns count cases gaining or losing a detection. This package uses the exact binomial form of the test and applies Holm correction across the three classes. A change in detections is not proof that normalization improved accuracy.

Reading the columns

n_usernames is the number of records analysed. usernames_with_entity counts those with at least one analytic label. entity_rate is that count divided by n_usernames. Multiply rates by 100 for percentages. ci95_low and ci95_high are the ends of a Wilson 95% confidence interval. mean_analytic_entities is the average number of detected analytic entities per record. Small intervals show precision under the statistical assumptions, not independent source verification.

What can be reproduced

The supplied code rebuilds detection rates, confidence intervals, Fisher tests, McNemar tests, and graphs from the saved aggregate counts. These calculations match the saved corrected p-values. Entity-label tables and average entity counts are retained from the earlier outputs. This is not a full rerun of spaCy on the original samples. That would require the original inference code, the exact sampled usernames, and matching model assets. No model accuracy, precision, recall, or F1 is claimed here.

Rerunning the tables and report

Run python reproduce_ner_statistics.py from this package. The original aggregate tables are in reference_outputs; rebuilt outputs are in reproduced_outputs. No raw usernames or private review sheets are included.
